Project Overview

This project analyzes the Global Superstore dataset obtained from Kaggle as a secondary data source. It follows the complete data analytics process, including data extraction, cleaning, analysis, and dashboard development to generate actionable business insights.

Tools and Technologies
Microsoft Excel and Python – Data extraction, cleaning, and preprocessing.
MySQL – Data analysis and SQL querying.
Power BI – Interactive dashboards and data visualization.
Artificial Intelligence (AI) – Assisted with data exploration, SQL query development, dashboard design, and interpretation of analytical insights.
Business Questions Addressed
Which products and categories generate the highest profit?
Which regions have high sales but low profitability?
Which customer segments are the most valuable?
Are discounts negatively impacting profit?
How does sales performance vary by month or season?
Which customers generate the highest revenue and profit?

Using SQL and Power BI, the project uncovers key business insights into sales performance, profitability, customer behavior, and regional trends. An interactive Power BI dashboard was developed to present the findings in a clear, user-friendly format, enabling stakeholders to explore the data and support data-driven decision-making.
